# Kit comercial de Taliron · Karla

Todo lo que necesitas para vender Taliron en videollamada: la guía, los datos de demo ya preparados,
las peticiones literales para cada demo, las plantillas de mensajes y la hoja de seguimiento.

## Empieza por aquí

1. **Lee la guía** (30 minutos): [`guia/Guia-Comercial-Taliron-Karla.pdf`](guia/Guia-Comercial-Taliron-Karla.pdf).
   También en Google Docs si prefieres comentar: pídele el enlace a Alberto.
2. **Instala Taliron en tu ordenador** siguiendo [`kit/INSTALACION.md`](kit/INSTALACION.md).
3. **Copia la carpeta `demo/` a tu Escritorio** (tal cual, con ese nombre). Ahí están las facturas,
   las fotos, las reseñas y los documentos que Taliron usa en cada demo.
4. **Ensaya las 8 demos** con [`demo/00-PETICIONES.md`](demo/00-PETICIONES.md) hasta que salgan sin pensar.
5. Antes de cada videollamada: [`kit/checklist-antes-de-cada-llamada.md`](kit/checklist-antes-de-cada-llamada.md).

## Qué hay en cada carpeta

- `guia/` — la guía comercial completa (PDF y versión web).
- `demo/` — el kit de demo: negocios ficticios con sus datos. Ver [`demo/negocios-ficticios.md`](demo/negocios-ficticios.md).
  - `clinica-dental/` — reseñas, pacientes, plantilla de presupuesto, tarifas, logo y fotos. Es el negocio del Instagram de demo.
  - `gestoria/` — 20 facturas PDF de proveedores de un taller (para «contabiliza estas facturas»).
  - `inmobiliaria/` — ficha y fotos de un piso (para «sube el piso» y «publícalo en Instagram»).
  - `restaurante/` — reseñas, platos para la carta, facturas de proveedores y mensajes de reserva.
  - `correo/` — 25 correos realistas para el Gmail de demo y el script que los mete.
- `kit/` — instalación paso a paso y checklist previa a cada llamada.
- `plantillas/` — mensajes de WhatsApp listos y la hoja de seguimiento.
- `herramientas/` — el script con el que Alberto generó los datos (no lo necesitas).
